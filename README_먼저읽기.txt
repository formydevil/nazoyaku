8권 표지 복구 v10 (Windows 10)

1. ZIP을 완전히 압축 해제합니다.
2. yeonseung-site 폴더에서 RUN_8_COVERS.bat 을 더블클릭합니다.
3. 실행 후 8권_수집_결과.csv, 8권_후보_검토.csv 파일을 확인합니다.
4. 새로 저장된 표지는 covers 폴더에 추가되고 books.js의 경로도 갱신됩니다.

기존 covers.zip의 85개 이미지가 이 배포본에 포함되어 있습니다. 다시 복사할 필요 없습니다.
8권 이외의 표지는 건드리지 않습니다. 미출간 3권은 검색하지 않습니다.
정식 제목/번역자 확인이 불충분한 표지는 자동 저장하지 않습니다.
웹사이트의 접근 제한이나 절판으로 일부 책은 실패할 수 있습니다.
자동 저장된 이미지도 사람이 최종 확인해야 합니다.
프로그램은 Windows에서 직접 실행해 검증하지 않았습니다.
