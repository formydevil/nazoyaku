이연승 번역서 홈페이지 v16: 새 책 등록 방법

1. ZIP 압축을 완전히 해제하세요.
2. yeonseung-site 폴더의 ADD_OR_UPDATE_BOOK.bat를 더블클릭하세요.
3. 제목만 입력하고 '온라인 검색'을 눌러 후보를 검색합니다.
4. 정확한 한국어판을 선택하면 서지정보와 표지 URL이 채워집니다.
5. 제목·저자·출판사·연도·링크·표지를 직접 확인한 뒤 저장하세요.
6. 저장 시 books.js를 백업한 후 도서 목록을 수정하고 표지를 covers 폴더에 다운로드합니다.
7. index.html을 새로 열거나 Ctrl+F5로 새로고침하면 반영됩니다.

- 이미 있는 도서는 제목이 일치하면 새 항목을 만들지 않고 수정합니다.
- '출간 예정' 도서를 등록하면 '출간 예정' 표시는 해제되고 출간연도 순으로 이동합니다.
- 기존 목록에 없던 제목도 신규 추가할 수 있습니다.
- Google 도서 공개 검색 API를 기본으로 사용합니다. 정확한 한국어판이 나오지 않을 수 있습니다.
- 카카오 책 검색 API를 추가하려면 KAKAO_API_KEY.txt 파일에 발급받은 REST API 키만 넣으면 됩니다.
- 온라인 검색 결과가 없거나 잘못된 경우 필요한 항목을 직접 입력하세요.
- 표지는 원본 이미지 URL에서 직접 다운로드하며 성공한 경우에만 로컬 파일을 연결합니다.
- 검색 결과는 자동 확정하지 않습니다. 동명이책, 다른 판본, 출간연도 오류가 발생할 수 있기 때문입니다.
- 정적 홈페이지 파일(index.html)만 웹에 업로드해 둔 경우 PC에서 저장한 변경은 자동으로 인터넷에 반영되지 않습니다.
  변경된 books.js와 covers의 새 이미지 파일을 웹 호스팅에 재배포해야 합니다.
- 오프라인에서 검색할 수 없고 Python 3가 필요합니다. 도서 검색 API의 품질/접근 제한에 영향을 받습니다.
